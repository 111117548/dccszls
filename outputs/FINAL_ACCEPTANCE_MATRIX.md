# Wchat V4.5 最终验收矩阵

## 自动化验收

运行：

```powershell
node --import ./tests/register-ts.mjs --test tests/*.test.ts
```

必须满足：

- 失败、跳过、待办均为 0。
- 四种模式均能产生 1—3 条有顺序的角色链。
- 模拟世界数据不能触发现实机会。
- 同一 EventLedger 机会只消费一次。
- 未读和每小时主动消息预算不能突破硬上限。
- 虚构群不接收现实世界上下文。
- 普通闲聊不写记忆；短期记忆过期；清除失败不恢复旧云端记忆。
- 图片资产必须绑定当前用户和群；视觉证据不泄露云文件 ID；故事图片不自动推进正式线索。

## 微信开发者工具验收

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 群列表 | 打开首页 | 展示四个群、模式标签、真实最近消息和未读数 |
| 路由隔离 | 各群分别发言后重进 | 消息和模式状态不串群 |
| 陪伴 | 发送“今天很累，只想有人陪会儿” | 首条接住感受；1—3 条；不是三份独立答案 |
| 打断 | AI 正在输入时发新消息 | 未显示旧内容取消，新话题优先 |
| 讨论 | 连续围绕同一决策发言四轮 | 阶段进入“形成结论”，能区分事实、假设和下一步 |
| 跨世界 | 发送“你们怎么看规则和冒险” | 三名角色从不同原创身份碰撞，不引用第三方 IP |
| 故事 | 选择检查信封，再选择追查时间 | 线索连续增加；角色不替用户做选择 |
| 主动节奏 | 在故事或跨世界群停留并保持不输入 | 约一分钟可出现一次角色回合；之后 20 分钟内不重复触发 |
| 真实天气 | 世界状态页同步 | 显示真实城市/区县、天气、来源、更新时间和定位精度 |
| 漂移 | 重复同步相近低精度坐标 | 不产生位置变化消息 |
| 本地资讯 | 配置联网搜索密钥后同步 | 最多 5 条近 7 日、带来源的本地结果；无结果时明确为空 |
| 现实问答 | 问“附近有什么新闻” | 只使用页面已有证据；无证据时明确无法确认 |
| 记忆 | 说“我喜欢散步”“我准备明天看展” | 只生成对应偏好与计划；可查看和清除 |
| 图片上传 | 点击输入框右侧圆形“+”，从相册选择一张图 | 输入框不被按钮挤压；安全通过后图片气泡立即出现，识别继续在后台完成；超过 5MB 或安全检查失败时不发送 |
| 图片回应 | 分别在四个群上传同一图片 | 1—3 条角色链围绕图中可确认内容接话；各群角度不同，不输出识图报告 |
| 图片真实性 | 上传人物、截图和地点照片 | 不识别人物身份，不猜地点/时间/商家，不把截图文字冒充已核实事实 |
| 故事图片 | 在故事群上传图片 | 角色可讨论但不自动新增线索或替用户推进剧情 |
| 防刷屏 | 离开后再返回，多次同步无变化 | 无变化允许 0 条；3 小时不超过 30 条 |
| 云降级 | 暂停云函数后聊天 | 仍可本地回退，且不把模拟信息称为真实 |

## 真机发布前阻断项

以下任一未完成，不应上传公开正式版：

- 五个云函数未全部部署或环境变量未配置。
- 五个数据库集合、权限或组合索引缺失。
- 定位隐私声明、AI 标识、用户记忆清除说明未在正式隐私政策中体现。
- 内容安全、投诉举报、年龄策略、服务协议和账号级数据删除未完成。
- 现实来源被模型扩写为不存在的新闻、POI、交通或活动。
- 任何群在用户没有输入和没有真实机会时持续重复刷消息。
