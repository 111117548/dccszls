# V4.5 附近资讯部署说明

## 结果边界

本阶段提供城市/区县级“附近资讯”，不是米级附近新闻：

- 只向腾讯云传城市和区县名称，不发送经纬度。
- 只保留近 7 日、HTTPS、有标题/摘要/来源/发布时间且能命中城市或区县的结果。
- 每次最多展示 5 条，云函数实例内缓存 30 分钟。
- 用户可在“世界状态”查看并复制原文链接，也可在群里询问“附近有什么新闻”。
- 没有可靠结果时保持为空；新闻不会在 V4.5 主动触发群消息。
- POI、活动真伪判断、道路和实时交通仍未接入。

## 需要准备

需在腾讯云开通“联网搜索 API”，并创建该产品的服务 API KEY。

接口文档：

- https://cloud.tencent.com/document/product/1806/130615

注意：这里需要的是联网搜索产品的 `sk-...` 服务 API KEY，不是微信 AppSecret，也不是腾讯云 SecretId/SecretKey。

## 部署 `localIntelSnapshot`

1. 在微信开发者工具中确认当前项目已选择正确的云开发环境。
2. 找到 `cloudfunctions/localIntelSnapshot`。
3. 右键云函数，选择“上传并部署：云端安装依赖”或当前工具版本中的同义选项。
4. 打开云函数配置，在“环境变量”中新增：

   - Key：`TENCENTCLOUD_WSA_APIKEY`
   - Value：联网搜索产品生成的 `sk-...` API KEY

5. 云函数超时建议设为 15 秒，内存 256 MB 即可。
6. 保存配置后重新上传并部署该云函数。

不要把 API KEY 写入小程序源码、聊天消息、截图或 Git。仓库中的 `.env.example` 只有变量名，不含真实密钥。

## 重新部署 `groupChat`

本次同时更新了模型可接收的世界证据结构和真实性提示词。因此还要右键
`cloudfunctions/groupChat`，重新上传并部署；原有 DeepSeek 环境变量保持不变。

## 验证

1. 微信开发者工具重新编译。
2. 打开“世界状态”，点击“同步真实世界状态”。
3. “附近资讯”应出现以下三种状态之一：

   - 找到 1—5 条带来源的真实结果；
   - 当前没有检索到可核验的近 7 日本地资讯；
   - 明确的配置或服务错误。

4. 点击一条资讯，确认能复制 HTTPS 原文链接。
5. 进入群聊发送“附近有什么新闻？”。
6. 首条回复必须复述真实标题并说明来源和发布日期；没有证据时必须明确无法确认。

## 常见问题

- `local_news_service_not_configured`：云函数没有配置 `TENCENTCLOUD_WSA_APIKEY`。
- `UnauthorizedOperation`：API KEY 错误，或不是联网搜索产品的服务 API KEY。
- `ResourceNotFound`：联网搜索服务尚未开通。
- `ResourceUnavailable`：产品资源欠费或不可用。
- 返回 0 条：近 7 日结果未通过城市/区县相关性、HTTPS、发布时间或去重校验；这是安全空结果，不应让 AI 补写。

## 成本与隐私

- 调用发生在前台世界同步时，不随每个 AI 气泡调用。
- 30 分钟内相同城市/区县优先命中云函数缓存。
- 新闻查询直接使用已同步证据，不额外调用搜索接口。
- 上线前应在隐私说明中列明：城市/区县会被用于获取本地资讯；精确经纬度不会发送给新闻服务。
- 搜索摘要仅用于发现和概览，原文版权及事实更新以来源网站为准。
