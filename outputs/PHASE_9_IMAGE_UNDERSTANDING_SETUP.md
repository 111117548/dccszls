# 阶段 9：单图上传、理解与群聊回应

## 已实现

- 聊天输入区左侧增加图片按钮，支持从相册或相机单次选择一张图片。
- 客户端优先压缩到最长边约 1600 像素，压缩后硬上限 5MB；支持 JPEG、PNG、WebP。
- 图片上传到 `user-images/{groupId}/...` 云存储路径，并在 `wchat_group_assets` 以 `OPENID + groupId + fileId` 登记。
- `imageVision` 下载并验证资产所有权，先调用微信图片内容安全；安全通过后图片立即进入聊天，视觉理解在后续异步完成。
- TokenHub 未配置、超时或识别失败时，已通过安全检查的图片仍保留在聊天中，并明确显示“图片已发送、暂时无法识别”。
- 视觉模型只返回受控证据：类别、摘要、物体、可见文字、显著细节、不确定项、置信度、模型和分析时间。
- `groupChat` 只接收受控视觉证据，不接收云文件 ID；一次生成 1—3 条角色接话。
- 四类群共享同一上传与识别底座：
  - 陪伴群：围绕用户当下分享和感受自然回应。
  - 讨论群：区分可确认观察、不确定项和下一步。
  - 跨世界群：以原创身份反差形成联想，但不把联想说成图中事实。
  - 故事群：图片默认是外部参考，不自动写入剧情线索。
- 用户离开页面时，未完成上传会清理；图片已发送但模型仍在回应时，结果保存为后台消息。

## 部署前准备

1. 在腾讯云 TokenHub 创建 API Key。
2. 在微信云开发数据库创建集合：

```text
wchat_group_assets
```

权限设为：

```json
{
  "read": false,
  "write": false
}
```

小程序端不应直接读写该集合；所有操作经过云函数。

新版 `groupPersistence` 在首次登记图片时会尝试自动创建缺失的
`wchat_group_assets` 集合，减少开发环境初始化失败。但自动创建不会替代权限和组合索引配置，
部署后仍需在控制台确认以下规则与索引。

为 `wchat_group_assets` 创建组合索引：

| 字段 | 排序 |
|---|---|
| `ownerOpenId` | 升序 |
| `groupId` | 升序 |
| `evidenceId` | 升序 |

`groupChat` 使用该索引按当前微信用户和群重新取得云端视觉证据；客户端提交的图片描述不会被直接信任。

## 云函数环境变量

在 `imageVision` 的“云端配置 → 环境变量”设置：

| Key | 推荐值 |
|---|---|
| `TOKENHUB_API_KEY` | 你在 TokenHub 创建的 API Key |
| `TOKENHUB_API_HOST` | `tokenhub.tencentmaas.com` |
| `VISION_MODEL` | `hy-vision-2.0-instruct` |

密钥只放在云函数环境变量，不能写入小程序源码、截图、Git 或交付压缩包。

## 部署顺序

在微信开发者工具中依次操作：

1. 右键 `cloudfunctions/groupPersistence`。
2. 选择“上传并部署：云端安装依赖”。
3. 右键 `cloudfunctions/imageVision`。
4. 选择“上传并部署：云端安装依赖”。
5. 右键 `cloudfunctions/groupChat`，选择“上传并部署：云端安装依赖”，使其能够按当前用户重新读取视觉证据。
6. 在云端确认 `imageVision` 超时时间为 30 秒，内存建议至少 256MB。
7. 重新编译小程序。

## 真机验证

1. 进入任一群，点击输入框左侧“+”。
2. 选择一张没有敏感内容的普通照片。
3. 应依次看到选择、压缩、上传、安全检查状态；安全通过后图片气泡立即出现，随后显示“正在识别图片内容”和“群友正在看图”。
4. 角色回应必须围绕画面可确认内容；不能猜拍摄地点、人物身份、时间、商家或新闻真实性。
5. 在输入框先写一句说明，再点击“+”，应发送“图片 + 说明”的混合消息。
6. 点击图片应打开微信图片预览。
7. 在故事群上传同一图片，确认线索数量没有自动增加。
8. 切断 TokenHub 配置后重试，图片应正常进入聊天，并明确提示“图片已发送，但暂时无法识别”；角色不得假装看见图片内容。

## 常见故障

| 表现 | 排查 |
|---|---|
| 提示 `imageVision 云函数尚未部署` | 部署 `imageVision` 并重新编译 |
| 提示“视觉模型尚未配置” | 检查三个 TokenHub 环境变量，修改后重新部署 |
| 提示安全检查暂不可用 | 检查云函数运行环境、微信内容安全接口权限和日志 |
| 图片上传失败 | 检查云存储配额、云环境选择、AppID 和网络 |
| 图片气泡出现但没有角色回复 | 查看 `imageVision`、`groupChat` 云函数日志和 TokenHub 余额/配额 |
| 云端报集合不存在 | 创建 `wchat_group_assets` 并关闭客户端直接读写 |
| 顶部显示“本机记录” | 重新部署 `groupPersistence`，确认会话集合存在；图片资产登记也依赖该云函数 |
| 提示“图片处理服务异常” | 打开 `imageVision` 云函数日志，复制 `[image-message]` 对应错误；新版界面会区分未部署、缺集合、超时和配置缺失 |

## 安全与隐私边界

- 图片属于用户内容，应在隐私政策中明确上传目的、处理服务商、保存期限和删除方式。
- 图片会由微信云存储、微信内容安全和腾讯 TokenHub 处理；公开发布前必须完成第三方处理告知和数据保留评审。
- 当前“清除群记忆”不等于删除图片。完整的聊天/图片删除入口和定期清理任务仍是公开版阻断项。
- 不允许用此能力做人脸识别、身份确认、医疗诊断、违法取证或敏感属性推断。
