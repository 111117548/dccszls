# V4.5 分阶段开发路线

## 阶段 0：决策与合规预检（已完成产品决策部分）

目标：确认 `OPEN_QUESTIONS.md` Q01—Q10，并对 Q11—Q15 建立责任人和截止时间。

当前状态：Q01—Q10 已于 2026-07-13 全部确认；2026-07-24 以 ADR-019 加入本地资讯；2026-07-26 以 ADR-020—022 冻结四群共同底座、模式主动回合和受控记忆，并以 ADR-023 加入受控单图理解，产品范围为 v1.3。Q11—Q15 的责任人与截止时间将在 V4.5b 公开发布筹备前落实。

退出标准：

- 高风险决策全部写入 `DECISIONS.md`。
- 明确 V4.5a 原型与 V4.5b 公开版边界。
- 运营主体、年龄策略、原创角色、部署地区明确。
- 已安排拟人化互动服务的专业合规咨询。

冻结点：产品范围冻结 v1.1。

## 阶段 1：交互与规则原型（实现完成，待开发者工具预览）

目标：用模拟世界数据验证群聊体验，不接真实模型也可以运行规则测试。

内容：

- 群列表、群聊、世界状态、授权失败态。
- GroupState、Topic、Opportunity、Director、Conversation Controller。
- 用户优先、动态锁定、冷却、消息预算、沉默。
- 原创角色卡 v1 和固定测试对话。

退出标准：规则单测通过；页面流程可点击；模拟数据始终标识。

当前结果：三张页面、原创角色、模拟世界状态和确定性规则引擎已实现；10 项自动化测试通过。因当前环境未检测到微信开发者工具，实际编译与模拟器视觉确认仍是退出条件。

冻结点：开发者工具预览通过后冻结交互和领域状态机。

## 阶段 2：真实世界数据（天气和本地资讯代码完成，等待部署；详细地址待地图服务）

目标：建立可信位置和天气证据链。

内容：

- 微信前台定位与权限降级。
- 逆地理编码、天气与预警适配器。
- 城市/区县级近 7 日本地资讯检索、30 分钟缓存、来源与原文留存；本阶段不做新闻主动触发。
- WorldSnapshot、变化检测、漂移过滤、缓存与配额。
- 来源、更新时间、精度、模拟状态展示。

退出标准：真机跨区/跨城样例、GPS 漂移、室内低精度、断网、数据过期测试通过。

当前结果：前台定位、天气实况/预警云函数、本地资讯云函数、证据封装、世界状态共享和失败降级已实现；需在云控制台配置供应商环境变量并完成真机验证。详细逆地理编码、街道和 POI 仍等待地图服务凭据。

冻结点：云函数部署、真机定位和地图逆地理编码验证后冻结 World API 和证据协议。

## 阶段 3：AI 对话闭环

目标：接入一个已备案候选模型，完成一次调用生成连续角色轮次。

内容：

- Model Gateway、结构化输出和版本记录。
- 意图与安全分类、Prompt Builder、角色卡。
- 事实许可、输出校验、重试和降级。
- Token、延迟和成本遥测。

退出标准：核心离线评测达标；无证据事实断言为 0；成本可测量。

冻结点：模型协议、提示词版本和角色卡 v1 冻结。

当前结果：`groupChat` 云函数、DeepSeek V4-Pro 单轮群聊、三角色提示词、JSON 输出校验、最近上下文、真实世界事实许可、精确坐标剔除和本地回退已实现。等待配置新的模型 API Key、部署云函数并完成真机对话评测；成本遥测当前仅保留供应商 usage，尚未落库聚合。

## 阶段 4：记忆与离线群生命（代码完成，等待云部署和真机离线仿真）

目标：实现 L1/L2、重开重建与严格防刷屏。

内容：

- L1/L2 摘要、来源、到期和删除联动。
- 服务端高价值事件与重开重建。
- 消息幂等、同机会去重、预算与熔断。
- 3 小时、24 小时离线仿真。

退出标准：所有离线场景 ≤硬上限；无真实机会时可以 0 条；重复机会只触发一次。

冻结点：主动消息策略 v1 冻结。

当前结果：EventLedger、真实世界变化去重、群列表前台机会处理、主动消息预算、未读硬上限、四群模式状态持久化、明确偏好/计划/情绪记忆和用户清除页均已实现并进入自动化回归。云端集合、索引和真机 3 小时/24 小时仿真仍是部署验收项。

## 阶段 4.1：多群模式化体验（代码完成，等待真机体验评测）

- 陪伴群：接住情绪、短追聊、角色故事。
- 讨论群：问题拆解、比较视角、形成结论。
- 跨世界群：原创身份反差和受控角色主动碰撞。
- 故事群：章节、线索、用户选择和角色间线索讨论。

退出标准见 `outputs/FINAL_ACCEPTANCE_MATRIX.md`。

## 阶段 4.2：单图理解（代码完成，等待云部署和真机评测）

- 相册/相机选择、客户端压缩、5MB 硬上限和云存储。
- 图片资产按 `OPENID + groupId` 登记，失败或取消时清理临时文件。
- 微信图片内容安全、TokenHub 视觉证据、证据白名单与不确定性约束。
- 四类群使用同一图片底座，但通过 ModeAdapter 形成陪伴、讨论、跨世界和故事四种回应方式。
- 图片及视觉证据随消息持久化；文字模型只接收净化摘要。

退出标准：见 `outputs/PHASE_9_IMAGE_UNDERSTANDING_SETUP.md` 和最终验收矩阵。

## 阶段 5：V4.5a 邀请制原型

目标：≤100 名 18+ 受邀用户验证留存与群生命感。

内容：

- 监控、反馈、灰度、成本上限、紧急停用开关。
- 隐私告知、AI 标识、基础删除和投诉渠道即使在原型也应提供。
- 不公开推广，不承诺后台连续定位。

退出标准：关键安全问题为 0；核心指标有真实样本；形成是否进入公开版的评审结论。

## 阶段 6：V4.5b 公开发布门槛

目标：完成公开服务所需合规与平台交付。

内容：

- 安全评估、算法备案/应用登记及公示材料。
- 未成年人策略、年龄识别、使用时长与依赖提醒。
- 极端情境干预、紧急联系人方案和人工流程。
- 服务协议、隐私政策、数据复制/删除、投诉举报。
- AI 生成标识、内容安全、日志和应急预案。
- 微信小程序备案、类目、地理位置接口、隐私声明和正式审核。

退出标准：专业合规签字/书面意见、备案评估材料齐备、发布阻断测试全部通过。

## 变更控制

任何新增需求先进入需求池。若改变阶段退出标准、数据模型、敏感数据范围、AI 调用数或合规义务，先更新基线和影响分析，不直接插入当前开发。
