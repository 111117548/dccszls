## 当前结论

1. 原需求的产品方向成立，但不能按“普通聊天小程序”直接开发和发布。
2. 产品高度符合“拟人化互动服务”定义。2026-07-15 起施行的新规给公开上线增加了安全评估、算法备案、未成年人保护、AI 标识、依赖风险提醒、数据复制/删除、投诉举报和极端情境干预等义务。
3. V4.5 应拆成两个门槛：
   - **可运行原型门槛**：验证群生命感、用户话题优先、真实世界变化和沉默机制。
   - **公开发布门槛**：补齐平台、隐私、内容安全和拟人化互动合规能力，并完成必要备案/评估。
4. “用户离开 3 小时产生 5—20 条未读”已改为 `0—20 条、硬上限 30 条`，且 0 条是合法结果。
5. 小程序关闭后不能依赖客户端持续定位或定时器。离线世界变化应采用服务端事件、受控轮询或用户重开时重建，不能承诺持续实时感知。
6. 第一阶段使用原创角色；“路飞型、五条悟型、林黛玉型”只保留为内部性格参考，不使用知名角色名称、头像、经典台词或足以造成混淆的设定。

## 冻结记录

用户于 2026-07-13 明确回复“全部接受推荐”。Q01—Q10 已写入 `DECISIONS.md`，基线自此冻结为 v1.0。Q11—Q15 是公开发布前必须完成的外部合规事项，不阻塞 V4.5a 邀请制原型，但阻塞 V4.5b 公开发布。

用户于 2026-07-14 确认将角色活人感规范写入项目。该规范现已升级为 `CLS v1.1`：当前三个角色与未来新增角色均使用同一套角色合同、硬门槛和评测协议，未经评测不得标记为“已准入”。

用户于 2026-07-14 确认角色应当能够自然延续对话、分享有来源的自身故事并进行受控的角色间交流。`CRA v1.0` 已写入基线；角色自主交流不等于随机事件生成，仍受用户优先、故事账本、机会、冷却、预算和沉默机制约束。

用户于 2026-07-24 要求角色能够知道附近新闻。该变更按 ADR-019 受控纳入：只做城市/区县级近 7 日本地资讯的查看与用户查询，保留来源和时效，不做新闻主动触发、交通、活动或 POI 推断。基线递增为 v1.1 并继续冻结。

用户随后确认先建立共同群底座，再分别开发陪伴、讨论、跨世界漫展和沉浸故事四类群，并要求角色能够在用户偏被动使用时形成有价值的群内进展。该变更按 ADR-020—022 纳入：四群共享运行、模型、持久化和安全底座；各自使用独立模式状态与角色职责；主动回合受冷却、消息预算和用户打断约束；用户明确偏好、计划和短期情绪采用可查看、可清除的受控记忆。基线递增为 v1.2 并继续冻结。

用户于 2026-07-26 要求开发上传图片并围绕图片回应。该变更按 ADR-023 受控纳入：单图经过云存储、内容安全和 TokenHub 视觉理解后形成结构化证据；四种群按各自模式回应；文字模型不接收云文件 ID，故事图片不自动成为剧情线索。基线递增为 v1.3 并继续冻结。

用户于 2026-07-27 明确要求角色成为行为上鲜活、持续存在的群成员，并要求群内围绕事情自然讨论，不再依赖固定条数或群活跃机制。该变更按 ADR-024 纳入：采用 `LGN v1.0`，以持续角色状态和 `ConversationState` 管理目标、观点、分歧、开放分支与承诺；Director 每次选择最有价值的下一项贡献，Controller 动态决定继续、等待、暂停或结束。基线递增为 v1.4 并继续冻结。
