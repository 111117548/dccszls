# 官方资料与复核记录

核验日期：2026-07-13；本地资讯来源补充核验：2026-07-24；图片理解来源补充核验：2026-07-26。

## 已核验的主要官方资料

1. [《人工智能拟人化互动服务管理暂行办法》](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)，国家互联网信息办公室等，2026-07-15 施行。与本产品直接相关的条款包括适用范围、安全责任、年龄和未成年人、极端情境干预、交互数据复制/删除、AI 身份提示、连续使用提醒、安全评估和算法备案。
2. [《生成式人工智能服务管理暂行办法》](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)，国家互联网信息办公室等。规定公众生成式 AI 服务的内容安全、个人信息、未成年人、投诉举报、安全评估和备案等要求。
3. [《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)，2025-09-01 施行。文本属于生成合成内容，规定显式/隐式标识和分发平台核验要求。
4. [国家网信办关于 2025 年生成式人工智能服务已备案信息的公告](https://www.cac.gov.cn/2026-01/09/c_1769688009588554.htm)。公告说明，直接调用已备案模型能力的应用或功能由地方网信办开展登记，并要求上线应用公示模型名称和备案号/上线编号。
5. [《中华人民共和国个人信息保护法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html)。第二十八条将行踪轨迹列为敏感个人信息，要求特定目的、充分必要和严格保护。
6. [个人信息保护政策法规问答（2026 年 1 月）](https://www.cac.gov.cn/2026-01/09/c_1769688003183197.htm)，国家网信办。明确连续精准定位轨迹属于常见敏感个人信息类别。
7. [和风天气开发服务](https://dev.qweather.com/)及[开发帮助](https://www.qweather.com/support/develop)。官方提供天气、预警、API/SDK、订阅和商业使用说明；具体套餐、归因和保留条款须在签约时再核验。
8. [腾讯云微搭：小程序隐私保护指引适配说明](https://cloud.tencent.com/document/product/1301/97930)。腾讯云文档说明，涉及个人信息的小程序需适配微信隐私保护指引并在调用相关隐私接口前完成同意流程。
9. [腾讯云联网搜索 API：服务 API KEY 方式](https://cloud.tencent.com/document/product/1806/130615)。官方文档给出 `SearchPro`、Bearer API KEY、时间过滤参数，以及 `Pages` 中标题、发布时间、来源 URL、摘要、站点和相关度字段；V4.5 本地资讯适配器据此实现。
10. [腾讯云 TokenHub 多模态理解](https://cloud.tencent.com/document/product/1823/130988)。官方文档给出境内 BaseURL、`image_url` 请求结构、支持图片理解的模型及输入限制；V4.5 单图适配器据此实现。
11. [腾讯云 TokenHub API 使用说明](https://cloud.tencent.com/document/product/1823/130078)。用于复核境内调用地址、模型参数和默认服务 ID。

## 发布前必须再次核验

微信官方开发文档站在本次检索环境中无法稳定打开，因此以下事项不能仅凭当前基线视为最终确认：

- `wx.getLocation`、前台位置更新和后台位置更新的最新基础库要求、适用类目与申请条件。
- `requiredPrivateInfos`、隐私保护指引、授权弹窗的最新配置格式。
- AI/深度合成相关小程序类目、资质、代码审核和内容安全接口要求。
- 网络合法域名、包体、订阅消息和备案的最新平台规则。
- 腾讯位置服务具体配额、QPS、商业授权、归因、缓存和数据展示限制。

处理原则：进入对应开发阶段前，用已认证的小程序后台和供应商控制台核验，并把截图/链接/确认日期写回决策记录。
