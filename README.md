# Wchat V4.5

微信原生 TypeScript 小程序。当前源码已经从单一陪伴群扩展为“一个共同底座 + 四种群模式”，并保留真实世界证据、模型失败降级、云端会话和严格防刷屏。

## 当前实现

- 四个可独立进入的群：
  - `晚风生活群`：情感陪伴、角色接话、有限主动分享。
  - `把话说清楚讨论群`：事实、假设、分歧、行动和阶段性结论。
  - `跨次元漫展会客厅`：三个原创世界身份的反差碰撞，不冒充第三方商业 IP。
  - `雾港来信·沉浸故事群`：连续线索、主观视角，角色不替用户选择。
- `GroupDefinition + GroupRuntime + ModeAdapter` 共同底座；群列表和聊天均使用稳定 `groupId`。
- 一次模型调用生成 1—3 条连续角色消息；后一角色必须接住上一角色。
- 用户可在角色输入期间打断，新的用户话题覆盖未显示的旧轮次。
- 陪伴群、故事群和跨世界群支持受控主动回合；首次自然跟进后进入冷却，并受消息预算和未读硬上限约束。
- 前台定位、和风天气实况/预警、城市/区县级本地资讯及来源展示。
- 世界变化检测、GPS 漂移过滤、Opportunity Engine、EventLedger、机会去重和重开补聊。
- 生产环境中的模拟数据不能触发现实消息；无可靠来源时明确未知。
- 云端按 `OPENID + groupId` 隔离消息、状态、事件和记忆，本地存储作为断网降级。
- 只提取用户明确表达的偏好、不喜欢、近期计划和短期情绪；支持查看和清除，失败删除带重试墓碑，避免云端旧记忆复活。
- 用户可从相册或相机选择一张图片；图片先进入私有云存储并通过内容安全检查，再由视觉模型生成受控证据，四种群模式围绕图中可确认内容自然接话。
- 图片附件与视觉证据按 `OPENID + groupId` 绑定；发送给文字群聊模型的是结构化摘要，不传云文件 ID。故事群中的用户图片默认只作外部参考，不自动成为剧情线索。
- AI 身份、虚构故事和现实数据边界持续可见。

## 产品边界

- 当前不接周边 POI、实时交通、活动真实性、视频理解、真人多人群聊或系统后台持续定位。
- 本地资讯需要单独的腾讯云联网搜索服务 API KEY；没有该密钥时功能保持明确空状态，不允许模型补写。
- 公开发布仍需隐私政策、内容安全、投诉举报、年龄策略、适用备案/登记和微信审核，不应把邀请制原型直接当成可公开运营版本。
