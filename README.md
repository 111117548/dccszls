## 安装质量标准

保留并结构化使用121条检查标准，来源包括：

- 壳体26项、灰斗19项、阳极系统16项；
- 阴极框架组合与阴极系统26项、振打系统6项；
- 支座与钢支架9项、进出口喇叭10项；
- 顶部起吊4项、高压进线5项。

AI检查生成的数据会写入室别、电场号、施工构件、空间位置、施工阶段和标准来源文件。

## 核心流程

1. 选择安装构件（A/B室、1～5电场或公共系统）。
2. 选择安装专业和具体检查条目。
3. 按条目的视觉要点拍照并填写排/列/轴线或灰斗编号。
4. 先检查照片清晰度、距离、遮挡和角度，再进行AI逐项分析。
5. 人工确认AI结果后生成开放协作整改单，可通过微信转发给任意人员上传整改证据并闭环。
6. AI质检页面本身不展示数字孪生；关联缺陷仍可在设备质量管理页面用于工程位置查询。

## AI质检开放协作闭环

- AI结果首先作为草稿，人工确认后才生成正式检查记录和整改清单。
- 整改单不绑定整改责任人，也不要求分享接收者授权昵称或手机号。
- 创建人本人或任何获得微信分享卡片的人，都可以上传整改照片、复测值和说明并完成闭环。
- 状态为“待整改 → 整改中 → 已闭环”，创建人可在历史记录中重新打开。
- 分享链接使用工单编号和安全协作令牌，只允许访问当前整改单。
- 跨微信设备协作依赖 `quality-ledger` 云函数及 `quality-rectification-orders` 云数据库集合。
- 分享接收人可自愿开启微信整改提醒；OpenID仅用于消息投递，不加入项目成员表，也不代表绑定责任人。
- 已闭环整改单会自动停止提醒；重新打开后，需要接收人再次开启提醒。

## 批量巡检分享整改

- 正式批量巡检提交后，只要存在缺陷，就会自动生成一张开放协作整改单，并与批量记录关联。
- V3.7升级前已经保存、但没有整改单的批量记录，会在质量台账中显示“生成整改协作单”入口。
- 生成后可直接点击“微信转发”；接收人无需绑定项目身份，可上传最多9张整改照片、复测值和文字说明并完成闭环。
- 接收人闭环后，创建人的批量巡检记录会同步显示“已闭环”，并保留完整整改证据与时间线。

## 微信整改提醒部署

1. 在微信公众平台“订阅消息”中配置整改提醒模板，字段需对应：`thing1` 工单编号、`thing2` 整改位置、`time3` 整改期限、`thing4` 提醒内容。
2. 新建仅云函数可读写的数据库集合：`quality-rectification-reminders`。
3. 在 `quality-ledger` 与 `rectification-reminder` 两个云函数中配置相同环境变量 `RECTIFICATION_REMINDER_TEMPLATE_ID`。
4. 在 `quality-ledger` 中配置 `RECTIFICATION_REMINDER_MODE`：普通模板填 `one_time`；只有已获微信长期订阅资格时才能填 `long_term`。
5. 上传并部署 `quality-ledger` 和 `rectification-reminder`，均选择“云端安装依赖”，并确认每天09:00的定时触发器已启用。

微信普通一次性订阅每次授权只能合法发送下一条消息，不能绕过平台限制无限每日推送。页面会在权限使用后提示接收人重新授权；长期订阅模板获批后，才可持续每日提醒。
