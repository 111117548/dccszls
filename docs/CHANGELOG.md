# 版本记录

本文件只保留当前产品演进所需的关键节点。早期按版本拆分的多份记录已在 2026-09-15 合并，避免仓库根目录被历史文件占满；完整修改细节仍可通过 Git 提交历史追溯。

## 当前版本 · 施工质量数字孪生平台

- 形成微信小程序原生 Canvas/WebGL 施工沙盘，支持 13 类部件累积展示、施工回放、部件选择、旋转与缩放。
- 首页采用企业蓝白界面与浅色数字孪生舞台，兼顾真机可读性和工业展示效果。
- 保留 AI 辅助检查、到货与安装进度、七类检验附表、质量台账、整改复验、报告导出与飞书协作。
- 增加移动端渲染降级、模型加载恢复、确定性施工机械动画和基础碰撞约束。
- 完善公开仓库说明、架构、安全、贡献指南及自动化检查。

## V6.0 · 企业化视觉升级

- 统一紫金龙净企业蓝白视觉、导航、状态色、卡片和移动端排版。
- 首页使用浅色工程产品展示风格，独立模型页保留深色工业模式。
- 优化窄屏文字、省略规则、触控尺寸及整改操作区。

## V5.2–V5.5 · 三维模型与交付能力

- 接入双室电除尘器轻量模型与小程序原生 GLB/WebGL 渲染。
- 依据 13 类施工部件控制累积可见性，并支持构件点击和缺陷空间标记。
- 完成飞书项目与炉号精确同步、AI 服务配置诊断和 Excel 导出容错。
- 增加模型加载状态、失败恢复、静态检查和运行时冒烟测试。

## V4.1–V5.1 · 项目化与质量闭环

- 支持多项目、多设备、施工阶段和设备树管理。
- 建立到货、安装检验、AI 缺陷、开放协作整改、复验和质量台账闭环。
- AI 与飞书密钥仅保存在云函数环境变量中，客户端不存储敏感凭据。
- 保留原始检验工作簿结构，支持云端回填导出。

## V3.x · 移动端工程化基础

- 建立首页驾驶舱、AI 巡检、批量巡检、整改分享、订阅提醒和报告流程。
- 完成移动端工业 UI、触控尺寸、弱网容错和数据迁移兼容。
- 引入项目作用域、稳定业务 ID、静态检查和安全边界。

## 历史追溯

需要查看某次修改的完整内容时，可使用：

```bash
git log --oneline --all
git show <commit>
```

GitHub 页面也可通过仓库顶部的 **Commits** 查看所有历史版本，无需在当前文件列表中保留重复副本。
